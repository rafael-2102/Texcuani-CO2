# Texcuani-CO2
Es un emprendimiento creado a base de la necesidad de comer rico, un sabor diferente pero unico, pero tambien pensando en tu salud. Es un emprendimiento que mezcla la sazón mexicana con la cultura colombiana, haciendo asi que nazca un emprendimiento unico, con u n sabor diferente y un razon unica de se existencia.
